## 🔬 Practical Labs

Each lab focuses on understanding **how and why** something works.

A typical lab workflow is:

```text
Understand
    ↓
Enumerate
    ↓
Analyze
    ↓
Experiment
    ↓
Document
    ↓
Verify
```

For example, in reverse-engineering labs:

```text
Binary
   ↓
file
   ↓
strings
   ↓
symbols
   ↓
disassembly
   ↓
understand logic
   ↓
reimplement
   ↓
verify
```

## 📖 Learning Approach

I am following a practical, hands-on approach:

> **Learn → Practice → Break → Analyze → Fix → Document**

Instead of only learning commands, I try to understand:

- What the command does
- Why it is used
- What the output means
- How the underlying technology works
- How the technique can be used defensively

## ⚠️ Ethical Use

All security testing and experiments in this repository are intended for:

- Personal learning
